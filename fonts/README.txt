Persian font for the /fa/ page: Vazirmatn (SIL Open Font License)

1. Download the font from https://github.com/rastikerdar/vazirmatn/releases
   (or `npm i vazirmatn`).
2. Copy  fonts/webfonts/Vazirmatn[wght].woff2  into this folder and rename it to:

       Vazirmatn-Variable.woff2

Until the file exists, the page automatically loads the same font from jsDelivr CDN.
